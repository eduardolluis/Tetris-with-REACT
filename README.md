# Tetris with React

A browser-based Tetris implementation built with React, with the game logic separated from the UI components.

## Highlights

- Playable Tetris board
- Tetromino definitions and movement logic
- Player and board controllers
- Reusable board and cell components
- Custom React hooks for game behavior

## Tech Stack

- React 18
- JavaScript
- CSS
- Create React App
